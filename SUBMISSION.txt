Title
ChangePointWatch - Semantic cumulative-sum change detection

Notes / Description
Built ChangePointWatch, a reusable GenLayer intelligent contract for semantic cumulative-sum change detection. Consensus emits a closed signal vector for each snapshot; deterministic per-dimension CUSUM detects sustained change rather than a one-off difference. One deployment supports multiple independently keyed records and callers. Inputs are public, caller-supplied snapshots; the contract does not automatically fetch or authenticate sources and moves no funds. GenVM lint, strict type checking, 5 direct tests and one five-validator GLSim flow passed. StudioNet verified successful finalized intelligent execution, final-state readback and matching deployed source.
